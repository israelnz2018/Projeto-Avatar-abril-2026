# Padrão dos popups de cursos

Este é o padrão oficial para os popups de venda exibidos aos alunos que já acessam a plataforma LBW.

## Estrutura comum

1. Nome do curso e uma descrição curta.
2. Bloco **O que você receberá a mais**.
3. Bloco **Conteúdo principal**, com no máximo quatro itens resumidos.
4. Uma única linha: **Você continuará acessando:** Comunidade LBW, IA Digital e recursos já liberados.
5. Investimento, botão de compra e opção para conhecer os pacotes LBW.

## Itens obrigatórios em todo curso

- Curso online completo com o nome específico do curso.
- Exercícios práticos e materiais de apoio.
- Avaliação e certificação de conclusão.

Não mencionar critérios internos da plataforma nesse bloco.

Quando um curso não possuir exercícios, esse item deve ser omitido e substituído pelos materiais específicos entregues. No curso **Como Criar Apresentações que Convencem**, informar os quatro templates de apresentação executiva em PowerPoint.

## Curso sem módulo estatístico

O bloco **O que você receberá a mais** contém somente os três itens obrigatórios. Não prometer Software LBW, relatórios estatísticos ou PowerPoint.

## Curso com módulo estatístico

Além dos três itens obrigatórios, informar:

- O módulo estatístico específico liberado no Software LBW.
- Gráficos, Análises Diversas, relatórios e PowerPoint, quando fizerem parte do pacote.

## Aplicação

Os cursos devem ser migrados para este padrão individualmente. Os primeiros cursos padronizados são:

- Como Aplicar a Cultura Lean.
- Análise Inferencial — Testes de Hipóteses.
- Análise Preditiva — Regressões, Correlações e Séries Temporais.
- Como Criar Apresentações que Convencem.
- Capabilidade de Processo Avançado.
- CEP — Controle Estatístico de Processo.
